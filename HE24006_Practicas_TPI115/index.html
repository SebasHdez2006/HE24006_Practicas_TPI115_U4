Síntesis de aprendizaje

Conclusiones

  1. Las solicitudes asíncronas permiten actualizar partes concretas de una interfaz sin recargar toda la página, por lo que mejoran la interacción y reducen trabajo innecesario del navegador.
  2. XMLHttpRequest permite comprender el ciclo HTTP de bajo nivel; Fetch ofrece una sintaxis basada en promesas más clara, pero exige verificar response.ok porque un error HTTP no siempre rechaza la promesa.
  3. La File API permite procesar archivos elegidos por el usuario sin enviarlos a un servidor. FileReader facilita las vistas previas y Blob permite crear descargas generadas desde el navegador.
  4. Las APIs REST organizan recursos mediante URL y métodos HTTP. GET consulta datos, POST crea recursos, PUT o PATCH actualiza y DELETE elimina; las operaciones que cambian datos deben ejecutarse con cuidado.
  5. Al integrar una API en una página conviene separar la consulta, el manejo de errores y el renderizado. Esto hace que el sitio sea más entendible, reutilizable y fácil de probar.
