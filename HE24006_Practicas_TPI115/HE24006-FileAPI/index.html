Parte II

Generación y descarga con Blob

Edite el mensaje si lo desea y genere tres formatos distintos. Cada botón crea un Blob, una URL temporal y un enlace de descarga.

El JSON incluye los datos de la práctica; el CSV contiene una lista de ejemplos de archivos procesables.

Conceptos aplicados

  • File: representa el archivo seleccionado y proporciona sus metadatos.
  • FileReader: permite leer texto o una URL de datos de forma asíncrona.
  • Blob: agrupa datos en memoria con un tipo MIME para generar un archivo descargable.
  • URL.createObjectURL: crea una URL temporal que el navegador puede descargar sin usar un servidor.
