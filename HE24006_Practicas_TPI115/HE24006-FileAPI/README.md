# Guía 44d File API

Demostración estática de la API de archivos del navegador para TPI115.

- Lee archivos TXT, CSV, JSON, XML e imágenes sin cargarlos a un servidor.
- Muestra metadatos y una vista previa del contenido con `FileReader`.
- Genera archivos TXT, JSON y CSV mediante `Blob` y `URL.createObjectURL`.

Abra `index.html` en un navegador moderno o sírvalo mediante cualquier servidor HTTP estático.
